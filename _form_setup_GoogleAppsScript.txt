한남하우스 예약 문의 폼 → Google Sheets + 메일 자동화 가이드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 시트 이미 만들어두셨어요 (한남하우스 렌탈하우스 예약 문의)
✅ 헤더 순서도 정확히 맞춰져 있음
✅ 아래 코드의 SHEET_ID 도 자동으로 채워져 있음

이제 STEP 1 (Apps Script 붙여넣기) → STEP 2 (배포) → STEP 3 (URL 회신)
3단계만 하면 됩니다. 약 3분.

────────────────────────────────────────
[STEP 1] Apps Script 열고 코드 붙여넣기
────────────────────────────────────────
1) 아래 시트 열기:
   https://docs.google.com/spreadsheets/d/1fkSrgogx3kEp3_r_k9YhkDqsHcvuUIkOml0RuXhhHR4/edit

2) 메뉴: 확장 프로그램 → Apps Script

3) 기본 코드 모두 지우고, 아래 코드 통째로 복사해서 붙여넣기

──────────── 아래부터 복사 ────────────

const SHEET_ID = "1fkSrgogx3kEp3_r_k9YhkDqsHcvuUIkOml0RuXhhHR4";
const NOTIFY_EMAIL = "hhannam.house@gmail.com";

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();

    sheet.appendRow([
      new Date(),
      data.name || "",
      data.contact || "",
      data.email || "",
      data.date || "",
      data.purpose || "",
      data.people || "",
      data.equipment || "",
      data.vehicles || "",
      data.message || ""
    ]);

    const body =
      "한남하우스 새 예약 문의가 접수되었습니다.\n\n" +
      "── 문의 내용 ──\n" +
      "이름/회사: " + (data.name || "-") + "\n" +
      "연락처:    " + (data.contact || "-") + "\n" +
      "이메일:    " + (data.email || "-") + "\n" +
      "희망날짜:  " + (data.date || "-") + "\n" +
      "촬영목적:  " + (data.purpose || "-") + "\n" +
      "예상인원:  " + (data.people || "-") + "\n" +
      "장비:      " + (data.equipment || "-") + "\n" +
      "차량:      " + (data.vehicles || "-") + "\n" +
      "요청사항:\n" + (data.message || "-") + "\n\n" +
      "────────────────────\n" +
      "접수 시각: " + new Date().toLocaleString("ko-KR") + "\n" +
      "시트 보기: https://docs.google.com/spreadsheets/d/" + SHEET_ID;

    MailApp.sendEmail({
      to: NOTIFY_EMAIL,
      subject: "[한남하우스] 새 예약 문의 — " + (data.name || "익명"),
      body: body
    });

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    MailApp.sendEmail(NOTIFY_EMAIL, "[한남하우스] 폼 에러", err.toString());
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet() {
  return ContentService.createTextOutput("Hannam House form endpoint");
}

──────────── 위까지 복사 ────────────

4) 디스크 아이콘 또는 Cmd/Ctrl+S 로 저장
   (프로젝트 이름은 자유 — 예: "한남하우스 폼 처리")

────────────────────────────────────────
[STEP 2] 웹앱 배포
────────────────────────────────────────
1) 우측 상단 [배포] → [새 배포]
2) 톱니 아이콘(유형) → "웹 앱" 선택
3) 설정:
   - 설명: "한남하우스 폼"
   - 다음으로 실행: "나"
   - 액세스 권한: "모든 사용자"   ← 중요!
4) [배포] 클릭
5) 권한 요청 화면이 뜨면:
   "권한 검토" → 본인 계정 선택 → "고급" → "안전하지 않은 페이지로 이동"
   → "허용"
   (본인이 작성한 스크립트라 안전합니다)
6) "웹 앱 URL" 이 표시됨 — 복사

   예시: https://script.google.com/macros/s/AKfycb...긴_문자열.../exec

────────────────────────────────────────
[STEP 3] URL 회신
────────────────────────────────────────
복사한 URL 을 채팅에 붙여넣어 주세요. 예:

   "Apps Script URL 은 https://script.google.com/macros/s/XXXX/exec 야"

→ HTML 의 REPLACE_WITH_YOUR_DEPLOYMENT_ID 부분을 자동으로 교체해드립니다.

────────────────────────────────────────
[STEP 4] 테스트 (URL 연결 후)
────────────────────────────────────────
1) 홈페이지 새로고침
2) 예약 문의 폼에 테스트 데이터 입력 후 제출
3) 확인:
   ✓ 시트에 새 행 추가
   ✓ hhannam.house@gmail.com 으로 메일 도착

문제 시:
- 메일 안 옴 → Gmail 스팸함 확인
- 시트에 안 들어감 → Apps Script 편집기에서 [실행] → 권한 재승인
- "권한 거부" → STEP 2 의 "모든 사용자" 액세스 권한 확인
